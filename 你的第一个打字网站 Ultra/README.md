## 打开

双击 `打字网站Ultra.html`，用 Edge 或 Chrome 打开即可。不需要安装、不需要联网、数据只存在本机浏览器里。

> 建议固定一个浏览器打开。更换浏览器或清理浏览器数据会导致练习进度丢失。

## 玩法

1. 顶部切「中文成语 / 英文单词」；
2. 选一个档位，进入练习；
3. 逐字母输入，打错会标红并计入正确率，必须打对才能继续；
4. 每个词一出现就先朗读一遍，你照着打；打完只响一声提示音，自动进入下一个，下一个出现时再朗读。

> 内置档位和英文都是逐字母输入；导入的、没有拼音的中文会用系统输入法打汉字。

> 语音是「先读后打」：朗读跟着题目走，不打字完成后再补读，所以手速再快也不会出现「上一题的读音慢半拍」。

**中文输入规则**

- 只打拼音字母，不用打声调，也不用切换输入法；
- 音节之间的空格自动跳过，`hu jia hu wei` 和 `hujiahuwei` 都行；
- `ü` 打 `v`（如「绿」`lǜ` 打 `lv`）；
- 每打完一个字的拼音，上方对应的汉字会点亮，拼音可一键隐藏当默写练。

**快捷键**

- `Enter` 重听当前词
- `Esc` 返回首页

## 导入自己的内容

首页的「＋ 导入我的词库」，可以粘贴文本，也可以选一个 `.txt` 文件。

**词组（一行一个）**

- 中文带拼音：`狐假虎威|hú jiǎ hǔ wèi` → 逐字母打拼音；
- 中文不带拼音：`实事求是` → 自动改用系统输入法打汉字；
- 英文：`apple|ˈæpl|苹果`（音标、释义可以省略）。

**文章**

直接粘整段文字。中文用输入法打、英文直接打，按字推进；每打完一句会朗读整句。

类型（词组 / 文章）和语言（中文 / 英文）默认自动判断，也可以在导入面板里手动指定。导入后出现在对应语言的分页里，卡片右上角的 × 可以删除。

限制：单篇文章 5000 字以内，词组 2000 条以内；浏览器本地存储约几 MB，满了会提示。

## 语音说明

朗读用的是浏览器自带的语音合成（Web Speech API），不联网、不下载音频。

- 词库练习：每个词出现时先朗读一遍，你再打；打完只响提示音。
- 文章练习：每打完一句朗读整句。
- 中文朗读需要系统装有中文语音包。没有的话页面会提示，可在「Windows 设置 → 时间和语言 → 语音」里添加中文语音，然后重启浏览器。
- 音色是本地合成音，能听懂但偏机械，不是真人录音。
- 生僻字可能有读不准的情况，遇到可以关掉「语音朗读」只练打字；`Enter` 可随时重听。
- 设置里可以选具体音色、调语速。

## 进度与统计

- 每个词连续打对 2 次记为「掌握」，打错清零；
- 首页每档显示掌握进度与历史最高速度；
- 每组结束显示速度、正确率、最高连击、用时，以及本组需要再看看的词；
- 设置里可开「只练未掌握的词」、「清空所有练习记录」。

## 自己加词

编辑 `data/` 下的四个文件，格式：

```js
// 中文：["成语", "带声调拼音，音节用空格分开"]
["狐假虎威", "hú jiǎ hǔ wèi"],

// 英文：["单词", "音标", "释义"]
["apple", "ˈæpl", "n. 苹果"],
```

注意：

- 中文成语的汉字个数必须和拼音音节数一致（4 字成语 = 4 个音节）；
- 拼音只写字母和声调，不要写数字声调；
- 英文单词用小写字母；
- 改完刷新页面即可生效。
